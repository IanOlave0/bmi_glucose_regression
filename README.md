# Laboratorio práctico: modelo de regresión lineal de 1 input: IMC vs Glucosa en la sangre

### Este es un laboratorio de práctica para implementar conocimientos básicos de ML con un modelo de regresión lineal de 1 input para IMC vs Glucosa en la sangre

El dataset utilizado fue https://www.kaggle.com/datasets/mragpavank/diabetes.

Tecnologías usadas:
* **Lenguaje:** Python 3.12.3
* **Cálculo Numérico:** NumPy
* **Procesamiento de Datos:** Pandas
* **Visualización:** Matplotlib
